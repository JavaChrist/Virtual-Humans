# Datasets

## Purpose

Test and regression datasets used to evaluate identity consistency, generation quality and prompt behavior.

## Can contain

- Categorized test sets (identity, image, video, voice, prompt, regression).

## Must not contain

- Authoritative character source data (see `characters/`).
- Credentials or generated production artifacts.

## Relationships

- Consumed by `validators/` and `workflows/` for evaluation and regression testing.
