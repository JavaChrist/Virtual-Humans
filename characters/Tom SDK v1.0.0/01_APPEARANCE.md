# 1. Objectif

Ce document définira l'apparence officielle et stable de Tom une fois validée.

Il prime, une fois complété, sur toute description textuelle improvisée. Les
références visuelles validées (`assets/identity/`) priment sur ce texte.

---

# 2. Base de travail (non verrouillée)

Base connue, fournie comme point de départ — **à valider**, pas une autorisation
d'inventer des détails :

* homme sympathique d'environ trente ans ;
* cheveux bruns ondulés ;
* barbe brune courte et soignée ;
* visage chaleureux ;
* attitude naturelle et rassurante ;
* style crédible, moderne et accessible ;
* peut tenir un smartphone dans la main droite lors des présentations.

---

# 3. Éléments À VALIDER (ne pas inventer)

Les éléments suivants sont **non définis** et doivent être validés :

```text
Couleur exacte des yeux: À VALIDER
Origine perçue / type ethnique: À VALIDER
Taille exacte: À VALIDER
Mensurations / carrure précise: À VALIDER
Dimensions précises du visage: À VALIDER
Coupe de cheveux définitive: À VALIDER
Style de barbe définitif: À VALIDER
Détails de peau (grains, marques): À VALIDER
```

Aucun prompt ne doit fixer ces valeurs tant qu'elles ne sont pas validées.

---

# 4. Niveau de réalisme

```text
Photorealistic Virtual Human
```

Tom doit ressembler à une personne crédible filmée dans des conditions réelles
(pas de rendu cartoon, anime, poupée, 3D artificielle ou plastique).

---

# 5. Références d'identité

Les références officielles de Tom sont stockées dans `assets/identity/` (images de
Tom en place). Ensemble cible :

```text
front, three-quarter-left, three-quarter-right,
profile-left, profile-right,
full-body-front, full-body-three-quarter,
neutral-expression, soft-smile,
+ une image maître (master face)
```

---

# 6. Continuité

Une fois validée, la même identité visuelle devra être conservée entre portraits,
plein-pied, miniatures, vidéos, fonds verts, publicités et réseaux sociaux.
