# 1. Objectif

Ce document définira le langage caméra officiel de Tom (cadrages, focales, mouvements,
angles) une fois validé.

---

# 2. Base de travail (non verrouillée)

Base générique cohérente avec un présentateur crédible et moderne :

* cadrages courants : portrait tête-épaules, buste, plan taille, plein-pied ;
* contact caméra naturel pour l'adresse directe ;
* mouvements sobres (peu ou pas de mouvements brusques) ;
* lumière naturelle ou douce et homogène ;
* formats verticaux (9:16) pour le social, horizontaux (16:9) pour le web.

Ces éléments sont une **base à valider**, pas des règles définitives.
