# 1. Objectif

Ce document définira la garde-robe officielle de Tom (masculine, crédible, moderne,
accessible) une fois validée.

---

# 2. Structure des tenues

La structure d'inventaire est préparée et compatible avec le runtime :

```text
assets/outfits/LOOK_001 … LOOK_010/
  ├── look.json      (métadonnées de la tenue)
  ├── look.md        (description)
  ├── look.png       (rendu tenue)
  └── thumbnail.png  (miniature)
```

> ⚠️ Les images (`look.png`, `thumbnail.png`) sont désormais celles de Tom.
> Certains descripteurs texte (`look.json`, `look.md`) héritent encore de formulations
> de Mei et sont en cours d'alignement ; les valeurs restent **À VALIDER**.
