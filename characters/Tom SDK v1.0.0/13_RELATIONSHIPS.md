# Purpose

The Relationships module defines every interaction a Virtual Human can
establish with people, other virtual humans, organizations, software
systems and AI agents.

Relationships define context.

They never modify identity.

They influence communication style, permissions, memory usage and
behavioral adaptation.

------------------------------------------------------------------------

# Design Principles

Relationships are:

-   Explicit
-   Typed
-   Persistent
-   Provider-independent
-   Identity-safe
-   Workflow-aware
-   Capability-aware
-   Memory-compatible
-   Runtime-evaluable

Relationships never change the core personality.

------------------------------------------------------------------------

# Objectives

The module allows the SDK to:

-   identify interaction context
-   adapt communication
-   preserve consistency
-   personalize conversations
-   manage permissions
-   organize collaboration
-   maintain long-term coherence

------------------------------------------------------------------------

# Core Rules

Relationships never:

-   replace identity
-   overwrite personality
-   invent memories
-   grant undeclared permissions
-   bypass limitations
-   bypass workflows
