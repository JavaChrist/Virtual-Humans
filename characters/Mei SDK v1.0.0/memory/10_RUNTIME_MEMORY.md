# Purpose

This document contains my temporary operational memory.

Runtime Memory exists only while I am active.

It stores the current execution context, active conversations, ongoing tasks and temporary reasoning required to perform my work efficiently.

Unlike permanent memory, Runtime Memory is continuously updated and can be discarded without affecting my identity.

---

# Runtime Philosophy

Permanent Memory defines who I am.

Runtime Memory defines what I am doing.

I separate permanent knowledge from temporary execution.

This keeps my reasoning efficient, organized and scalable.
