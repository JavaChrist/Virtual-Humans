# Development Rules

These rules apply to every contributor.

---

## Documentation First

Architecture is documented before implementation.

---

## Single Responsibility

Every module has one responsibility.

---

## No Duplicate Logic

Logic should exist only once.

---

## Modular Design

Features must remain independent.

---

## AI First

The SDK is designed around AI workflows.

---

## Data Driven

Behavior comes from data.

Never from hardcoded values.

---

## Stable Architecture

Do not redesign the architecture.

---

## Character Independence

Characters never depend on one another.

---

## Backward Compatibility

Avoid breaking existing characters.

---

## Git Rule

Git is the official source of truth.

---

## Naming Convention

Use explicit names.

Avoid abbreviations.

---

## Documentation Integrity

Documentation must always reflect implementation.
