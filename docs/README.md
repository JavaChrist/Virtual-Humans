# Documentation

## Purpose

Human-readable documentation for the Virtual Humans SDK: architecture, guides, governance and roadmap.

## Contents

- `AUDIT.md`: complete technical audit of the current web app (site).
- `ARCHITECTURE.md`: high-level architecture overview.
- `GETTING_STARTED.md`: first steps with the SDK.
- `CHARACTER_CREATION_GUIDE.md`: how to create a new character SDK.
- `PROVIDER_INTEGRATION_GUIDE.md`: how to add a provider adapter.
- `VALIDATION_GUIDE.md`: how validation works.
- `VERSIONING.md`: versioning rules.
- `GOVERNANCE.md`: decision and review process.
- `AI_COMMAND_CENTER_INTEGRATION.md`: integration with the AI Command Center.
- `ROADMAP.md`: planned evolutions.
- `archive/`: historical documents.

## Must not contain

- Authoritative standards (see `core/`) or schemas (see `schema/`).
