# Virtual Humans SDK

Standardized framework for creating, managing, generating, validating and versioning photorealistic virtual humans.

## Main directories

- `core/`: global standards
- `schema/`: machine-readable schemas
- `templates/`: reusable character SDK templates
- `characters/`: official Virtual Human SDKs
- `providers/`: provider adapters
- `workflows/`: generation and publication workflows
- `validators/`: automated validation tools
- `datasets/`: test and regression datasets
- `docs/`: SDK documentation
- `examples/`: implementation examples
- `scripts/`: repository utilities

## Current official character

- Mei SDK v1.0.0
